# Integration Service

Python-based service for third-party integrations.

## Overview

This service handles integrations with:
- Travel booking APIs
- Hotel/accommodation providers
- Flight search services
- Maps and location services
- Weather APIs

## Tech Stack

- Python 3.11+
- FastAPI (planned)
- httpx for async HTTP

## Setup

```bash
# Create virtual environment
python -m venv venv

# Activate (Windows)
.\venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```
